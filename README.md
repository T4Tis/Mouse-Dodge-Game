Use the movement of your mouse to dodge

Click Start to initiate the dodge game

You have 3 lives

**Web Link:** https://t4tis.github.io/Mouse-Dodge-Game/

## Debug Controls

| Action | Key | Description |
| :--- | :--- | :--- |
| **Triangle Attack** | `Up Arrow` | Fires triangle attack |
| **Laser Attack** | `Down Arrow` | Fire laser attack. Each press increases speed |
| **Ball Attack** | `Right Arrow` | Fires ball attack |
| **Stop Attacks** | `Esc` | stops current Laser and Ball attacks |
